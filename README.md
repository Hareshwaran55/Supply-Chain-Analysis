# Supply-Chain-Analysis
An end-to-end pandas project that cleans messy supply chain data (mixed date formats, invalid values, duplicates, missing entries) and explores delivery, supplier, cost, and defect trends using group by, pivot tables, rolling windows, and time-series analysis.

📁 Project Structure
.
├── supply_chain_analysis.py          # Full pipeline (Stages 1–4)
├── supply_cahin_data.xlsx            # Raw input dataset
├── supply_chain_data_cleaned.xlsx    # Cleaned output (generated by script)
└── README.md
