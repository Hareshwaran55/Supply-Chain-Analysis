# Supply-Chain-Analysis
An end-to-end pandas project that cleans messy supply chain data (mixed date formats, invalid values, duplicates, missing entries) and explores delivery, supplier, cost, and defect trends using group by, pivot tables, rolling windows, and time-series analysis.

Overview
Tool used: Python (pandas, NumPy) via script or Jupyter Notebook
Dataset: Single shipment-level table, 6,150 rows × 25 columns
Goal: Clean a messy real-world dataset and answer business questions about delivery performance, suppliers, warehouses, costs, and defects using pandas

🧹 Data Cleaning
Identified and removed 149 duplicate rows
Handled missing values across multiple columns using category-aware median imputation (fallback to global median) for numeric fields, and "Unknown" for categorical fields
Parsed a column containing three mixed date formats in one field (MM/DD/YYYY, YYYY-MM-DD, DD-Mon-YYYY) and nulled out logically invalid dates (delivery before shipment)
Converted numeric columns stored as text ("unknown", "--") using coercion, turning invalid entries into nulls before imputing
Detected and corrected negative values in fields that can't logically be negative (quantity, cost, defect rate)
Standardized text casing and trimmed whitespace across all text columns
Validated the cleaned dataset (no duplicates, no negatives, dtype checks)
📊 Analysis

Business questions answered using pandas, including:

Delivery performance and on-time rate
Supplier performance ranked by rating, defect rate, and delay
Warehouse inventory levels vs. reorder thresholds
Shipping-mode and carrier performance comparison
Regional and product-category cost and delay breakdown
Defect-rate trends by category and inspection outcome
Monthly shipment volume and cost trends
Advanced techniques: groupby(), agg(), transform(), merge(), pivot_table(), rank(), shift(), rolling(), cut(), multi-index operations, and time-series resampling

▶️ Usage

Place supply_chain_data.xlsx in the same directory as the script, then run:

bash

The script prints results for every step to the console and writes the cleaned dataset to supply_chain_data_cleaned.xlsx.
